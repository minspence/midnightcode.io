# Midnightcode.io
This is a website built using Next.js 16, App Router, Tailwind, and Sanity.

## Site Details
This is a 4-page website: Home, About, Projects, and Contact page.

Sanity hosts all project details:
- Images
- Descriptions
- Slug links
- URL links

### Recent changes
Domain name changes from Midnight-code.tech to Midnightcode.io
